# tarouttoo-skills

Личные скиллы для ИИ-агентов (pi, Claude Code и других, поддерживающих
формат `SKILL.md`). Каждый каталог — отдельный скилл.

## Скиллы

### `tpu-doc-template`

Единый шаблон форматирования текста учебных работ ТПУ (лабораторные,
практические, рефераты, статьи) в `.docx`.

- **SKILL.md** — правила: стили (Normal, Заголовки 1–3, Рисунок, Таблицы,
  Код), подписи по разделам («Рисунок 2.1 – Название»), перечисления,
  формулы, источники по ГОСТ 7.0.100, чек-лист аудита и сводка команд
  WordCraft MCP.
- **template.docx** — эталонный документ с настроенными стилями и
  демо-галереей (по одному образцу каждого объекта оформления).

Шаблон извлечён из реальной выпускной квалификационной работы ТПУ
(Инженерная школа неразрушающего контроля и безопасности).

**Установка:**

```bash
cp -r tpu-doc-template ~/.agents/skills/
# или
ln -s "$(pwd)/tpu-doc-template" ~/.agents/skills/tpu-doc-template
```
