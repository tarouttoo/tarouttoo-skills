# Шаблон форматирования учебных работ ТПУ

Шаблон извлечён из реальной выпускной квалификационной работы (ТПУ,
Инженерная школа неразрушающего контроля и безопасности). Охват —
**только форматирование текста основной части**: титульные листы, задания,
рефераты и структура документа в шаблон не входят.

## Файлы

- `template.docx` (лежит рядом с этим SKILL.md) — эталонный документ:
  содержит все настроенные стили и демо-галерею (по одному образцу каждого
  объекта оформления). Это источник стилей и образец внешнего вида.

## Быстрый старт

**Сценарий А — работа с нуля.** Скопируйте `template.docx` как основу
(`cp template.docx <работа>.docx`), откройте в WordCraft, удалите
демо-галерею (страницы 1–3), пишите контент поверх готовых стилей.

**Сценарий Б — стиль в существующий документ.** Откройте чужой документ и
скопируйте стили из эталона: `styles.copyFrom {path:
"…/tpu-doc-template/template.docx"}`, затем применяйте их командами
`para.style`. Имена стилей после копирования: `Normal`, `Heading 1`,
`Heading 2`, `Heading 3`, `Рисунок`, `Таблицы`, `Код`, `Table Grid`.
Перед применением проверьте список командой `styles.list`.

## Страница

| Параметр | Значение |
|---|---|
| Формат | A4 (210 × 297 мм) |
| Поля | левое 3,0 см; правое 1,5 см; верхнее 2,0 см; нижнее 2,0 см |
| Номер страницы | внизу по центру, обычным шрифтом |
| Ориентация | книжная (широкие таблицы/рисунки — отдельный альбомный раздел) |

## Стили

| Стиль (имя в Word) | Параметры | Когда применять |
|---|---|---|
| `Normal` (Обычный) | Times New Roman 14 pt, чёрный; по ширине; отступ первой строки 1,25 см; интервал 1,5; интервалы до/после 0 | весь основной текст, включая пункты перечислений |
| `Heading 1` (Заголовок 1) | TNR 14 pt полужирный, ПРОПИСНЫМИ, по центру; **с новой страницы**; автонумерация «1»; keepNext | разделы: 1, 2, 3… |
| `Heading 2` (Заголовок 2) | TNR 14 pt полужирный, с абзацного отступа 1,25 см; автонумерация «1.1»; keepNext + keepLines; **не** с новой страницы | подразделы |
| `Heading 3` (Заголовок 3) | TNR 14 pt полужирный, с абзацного отступа; автонумерация «1.1.1»; keepNext + keepLines | пункты |
| `Рисунок` | TNR 14 pt, по центру, без отступа первой строки, интервал 1,5 | подпись ПОД рисунком |
| `Таблицы` | TNR 14 pt, одинарный интервал, без отступа первой строки | подпись НАД таблицей и НАД листингом; текст ячеек таблиц (с ручным размером 12 pt) |
| `Код` | Courier New 10 pt, одинарный интервал, без отступа первой строки, язык en-US | листинги кода |
| `Table Grid` | все линии 0,5 pt чёрные | все таблицы данных |

Номера заголовков (1, 1.1, 1.1.1) добавляет автонумерация стиля — **не
набирайте их вручную**. Текст заголовка пишите без номера и без точки на
конце: «Типы интегральных схем», а не «1.1.2. Типы интегральных схем».

Разделы, не нумеруемые автонумерацией (если работа их содержит: Введение,
Заключение, Список использованных источников), оформляются стилем
`Heading 1` с подавленной нумерацией.

## Правила по объектам

### Перечисления (важно!)

Пункт перечисления — это **обычный абзац стиля `Normal`, начинающийся с
маркера**: `– `, `1) `, `а) `. Никаких стилей списков и автоспосков.

- Первая строка (маркер + текст) стоит на отступе первой строки 1,25 см —
  это даёт сам стиль `Normal`, ничего дополнительно настраивать не нужно.
- Строки переноса внутри пункта уходят **к левому полю (отступ 0)**, а не
  «столбиком» на уровень маркера. Это следствие `indentLeft = 0`.
- Выравнивание по ширине, интервал 1,5 — как у обычного текста.
- Тире маркера — символ «–» (en dash), после него пробел.

### Рисунки

1. Картинка — отдельным абзацем, выравнивание по центру, обтекание
   «в тексте» (inline). Не вставляйте картинку внутрь абзаца подписи.
2. Подпись ПОД рисунком, отдельным абзацем стиля `Рисунок`.
3. Формат: `Рисунок <раздел>.<порядковый> – Название` — например
   `Рисунок 2.1 – Структурная схема системы`. Тире — en dash, после номера
   точки нет. Название с прописной буквы, точка в конце не ставится.
4. Нумерация **по разделам**: в разделе 2 первый рисунок — «Рисунок 2.1».
5. Ссылка в тексте до рисунка: «…представлена на рисунке 2.1» или
   «(рисунок 2.1)».

### Таблицы

1. Подпись НАД таблицей, отдельным абзацем стиля `Таблицы`:
   `Таблица <раздел>.<порядковый> – Название` (например, `Таблица 1.2 –
   Сравнение алгоритмов`). Нумерация по разделам, как у рисунков.
2. Сама таблица — стиль `Table Grid` (все линии 0,5 pt чёрные).
3. Текст ячеек: 12 pt, одинарный интервал (абзацы ячеек — стиль
   `Таблицы` + размер 12). Шапка таблицы — полужирная, по центру;
   данные — как правило, по левому краю.
4. Таблица по ширине текстового поля (16,5 см).

### Листинги и код

1. Подпись НАД кодом, абзацем стиля `Таблицы` (тем же, что у таблиц):
   `Листинг <раздел>.<порядковый> – Название`. Нумерация по разделам.
2. Каждая строка кода — абзац стиля `Код` (Courier New 10 pt, одинарный
   интервал, без отступа). Абзацы идут подряд, без пустых строк между
   ними, без нумерации строк.
3. Код не разрывайте произвольно: перенос длинной строки — с отступом
   продолжения.

### Формулы

1. Формула — отдельной строкой, по центру.
2. Номер формулы — в круглых скобках по правому краю той же строки:
   `(2.5)` — номер раздела и порядковый номер в разделе.
3. Техника (WordCraft): абзац `Normal`, табуляция по центру ≈ 8,25 см и
   по правому краю 16,5 см (`para.tabs`), затем `\t<формула>\t(2.5)`;
   сама формула — `insert.equation`.
4. Ссылка в тексте: «…по формуле (2.5)».

### Список использованных источников

Записи — абзацы `Normal`, нумерованные вручную («1. », «2. »), оформление
по ГОСТ 7.0.100-2018. Краткие образцы:

- Книга: `1. Иванов, А. А. Робототехника : учебник / А. А. Иванов. –
  Москва : Высшая школа, 2023. – 352 с. – ISBN 978-5-06-000000-0.`
- Статья: `2. Петров, Б. В. Планирование траекторий манипуляторов /
  Б. В. Петров, В. Г. Сидоров // Известия ТПУ. – 2024. – Т. 335, № 2. –
  С. 45–52.`
- Ссылка на источник в тексте — в квадратных скобках: «…как в [2]».

## Реализация в WordCraft (сводка команд)

| Действие | Команда |
|---|---|
| Открыть эталон / копию | `wordcraft_open_document` |
| Применить стиль | `wordcraft_execute {command:"para.style", params:{style:"Heading 2"}}` (или `para.normal`, `para.heading1`…) |
| Заголовки | `para.heading1`, `para.heading2`, `para.heading3` |
| Таблица со стилем | `wordcraft_insert_table {values, header:true, style:"Table Grid"}`, затем выделить её и `format.size {size:12}` |
| Картинка по центру | `insert.picture {path, width}`, затем `para.align {value:"center"}` и снять отступ: `para.indents {left:0, firstLine:0}` |
| Подпись по разделам | `references.caption {label:"Рисунок", chapter:1, separator:"–", position:"below"}` либо вручную текстом + `para.style {style:"Рисунок"}` |
| Формула с номером | `para.tabs {set:[{pos:234, align:"center"},{pos:468, align:"right"}]}` (в pt: 8,25 см ≈ 234 pt; 16,5 см ≈ 468 pt) + `insert.equation {latex, display:false}` |
| Текст листинга | вставить код построчно → `para.style {style:"Код"}` |
| Выравнивание/отступы | `para.align`, `para.indents {left, firstLine}` |
| Проверка результата | `wordcraft_render_page`, `wordcraft_inspect_document` (смотреть `style` и `props` блоков) |

Значения по умолчанию (TNR 14, интервал 1,5, отступ 1,25) уже зашиты в
стили — прямое форматирование текста основной части не применяйте, только
стили. Исключения с прямым форматированием: размер 12 pt в ячейках
таблицы, табуляции формулы, центрирование картинки.

## Чек-лист аудита (проверка чужого черновика)

1. Поля страницы 30/15/20/20 мм; номер страницы внизу по центру.
2. Весь основной текст — стиль `Normal` без прямых переопределений.
3. Заголовки — `Heading 1–3`, без номеров, набранных вручную, без точек
   после номеров; `Heading 1` начинается с новой страницы и набран
   ПРОПИСНЫМИ.
4. Каждая картинка — отдельный центрированный абзац; подпись под ней
   отдельным абзацем `Рисунок`, формат `Рисунок N.M – Название`.
5. Подпись каждой таблицы над ней, стиль `Таблицы`, формат
   `Таблица N.M – Название`; таблица `Table Grid`; ячейки 12 pt.
6. Код — стиль `Код`, подпись `Листинг N.M – Название` над ним.
7. Номера рисунков/таблиц/листингов уникальны и идут по разделам
   (в разделе N — N.1, N.2, …), ссылках в тексте соответствуют объектам.
8. Формулы по центру, номера `(N.M)` по правому краю.
9. Перечисления — абзацы `Normal` с маркерами «–»/«1)»/«а)»; переносы
   строк идут от левого поля, без висячих «столбиков».
10. Нет разнобоя тире/дефисов в подписях (везде en dash «–»).

## Так нельзя (ошибки, найденные в исходной ВКР)

- Сквозная нумерация объектов («Рисунок 1, 2, 3…» по всему документу) —
  только по разделам: `Рисунок N.M`.
- Дубли номеров («Рисунок 3» дважды) — следите за уникальностью.
- «Таблица 1.» с точкой после номера — только «Таблица 1.2 – Название».
- Точки после автономеров заголовков («1.1.2. Название»).
- Картинка, вставленная внутрь абзаца подписи.
- Автосписки Word с висячим отступом («столбиком») для перечислений.
- Ручной набор номеров разделов/подразделов вместо автонумерации стилей.
- Прямое форматирование (шрифт/размер/интервалы) поверх стилей в
  основном тексте.
